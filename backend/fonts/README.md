# Bundled fonts

The PDF generator bundles the variable TrueType files from the Google Fonts
`Noto Sans Devanagari` and `Noto Sans Kannada` families. The matching SIL Open
Font Licenses are included beside each font as `OFL-NotoSansDevanagari.txt` and
`OFL-NotoSansKannada.txt`.

- [Noto Sans Devanagari source](https://github.com/google/fonts/tree/main/ofl/notosansdevanagari)
- [Noto Sans Kannada source](https://github.com/google/fonts/tree/main/ofl/notosanskannada)
